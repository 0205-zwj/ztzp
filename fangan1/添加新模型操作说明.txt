【核心理解：编号 和 文件名 是两回事】

  · 网址里的 id=1、id=2、id=3  →  这是"构件编号"
  · models文件夹里的 1.glb、2.glb  →  这是"模型文件名"
  · 两者通过 data.js 里的配置对应起来
  · 文件名就叫 编号.glb，简单直接，没有 .min

  例如构件3：网址 id=3，模型文件就叫 3.glb

-----------------------------------------------------
【第一步：压缩模型】
-----------------------------------------------------

  1. 双击打开「一键压缩模型.bat」
  2. 把你从建模软件导出的大模型文件（比如 3.glb）
     直接拖到黑色窗口里，按回车
  3. 等它跑完，原文件就被替换成了压缩后的小文件
     （几十MB会变成几百KB）

  （第一次运行会自动联网下载压缩工具，耐心等一下）

-----------------------------------------------------
【第二步：把模型放进 models 文件夹】
-----------------------------------------------------

  把压缩好的 3.glb 复制到：
     E:\中铁装配\GitHub文档\gangjiegou\models\3.glb

-----------------------------------------------------
【第三步：修改 data.js】
-----------------------------------------------------

  用记事本打开：
     E:\中铁装配\GitHub文档\gangjiegou\data.js

  在最后一个构件的 } 后面，加上一段（注意前面有个逗号）：

    ,
    "3": {
        partId: "3",
        workNo: "你的加工号",
        projectName: "昆明长水国际机场项目",
        section: "你的分部工程",
        partType: "你的构件类型",
        material: "你的材质",
        spec: "你的规格",
        quantity: "1套",
        glbUrl: "./models/3.glb"
    }

  注意：
   · "3" 是构件编号，新模型依次用 3、4、5...
   · glbUrl 里的文件名要和实际文件一致
   · 每个构件编号只能出现一次，不能重复！

-----------------------------------------------------
【第四步：上传 GitHub】
-----------------------------------------------------

  1. 打开 GitHub Desktop
  2. 左下角 Summary 写：添加构件3
  3. 点 "Commit to main"
  4. 再点右上角 "Push origin"
  5. 等进度条跑完

-----------------------------------------------------
【第五步：访问 / 生成二维码】
-----------------------------------------------------

  链接格式（id后面只跟编号数字）：
     https://0205-zwj.github.io/gangjiegou/index.html?id=3

  把这个链接生成二维码，贴到对应构件上即可。

=====================================================
  常见问题
=====================================================

Q: 显示"构件信息未找到"？
A: 99%是网址id写错了。id后面只写编号（id=3），
   不要写成 id=3.glb 或 id=3.min。

Q: 显示编号但模型转圈加载不出来？
A: 模型文件没传上去，或glbUrl文件名和实际不一致。
   检查 models 文件夹里有没有 3.glb，GitHub上有没有。

Q: 想换某个构件的模型？
A: 新模型压缩后命名成相同文件名（如2.glb）覆盖旧的，
   data.js不用改，直接上传即可。

Q: 压缩坏了想找回原始大文件？
A: E:\中铁装配\GitHub文档\原始模型大文件备份_勿传 文件夹里有最初的4个原始模型（在仓库外面，不会被上传）。
   （新加的模型请自己保留好建模软件里的源文件）

Q: data.js改坏了页面乱了？
A: 检查括号{}、逗号、引号有没有漏，
   每个构件编号("1"、"2")只能出现一次。

=====================================================
  编号(id) 和模型文件名，能用英文/中文吗？
=====================================================

  推荐：网址 id 和 models 里的文件名都用「英文/数字/横杠/下划线」，
  中文名字放进 data.js 的显示字段里。这样二维码、微信、服务器最稳，不会乱码。

  例：构件叫 GZ45-21
    文件名：models/GZ45-21.glb
    data.js：
       ,
       "GZ45-21": {
           partId: "GZ45-21",
           workNo: "...", projectName: "...", section: "...",
           partType: "...", material: "...", spec: "...", quantity: "1套",
           glbUrl: "./models/GZ45-21.glb"
       }
    网址：index.html?id=GZ45-21

  例：构件叫"高铁门脸"（中文）
    网址 id 和文件名用英文/拼音/数字，中文只用于页面显示：
    文件名：models/GTML.glb
    data.js（id 键用英文；partId 想显示中文就写中文）：
       ,
       "GTML": {
           partId: "高铁门脸",
           workNo: "...", projectName: "...", section: "...",
           partType: "...", material: "...", spec: "...", quantity: "1套",
           glbUrl: "./models/GTML.glb"
       }
    网址：index.html?id=GTML   （扫码后页面"构件编号"显示：高铁门脸）

  不推荐但技术上可行：直接用中文当 id 和文件名（高铁门脸.glb、id=高铁门脸），
  网址中文需转码，个别手机/服务器可能乱码，所以不建议。

=====================================================
  lib 文件夹是干什么的？（别删，首次部署提交一次即可）
=====================================================
  lib/model-viewer.min.js          3D模型查看引擎（原本从国外CDN现下载，已放本地）
  lib/draco/draco_decoder.wasm     解压"压缩模型"的解码器（约188KB，手机/电脑实际用它）
  lib/draco/draco_wasm_wrapper.js  解码器加载脚本（约57KB）
  lib/draco/draco_decoder.js       极老浏览器的备用解码器（正常不会下载，留着即可）

  作用：这些原本要从 google(gstatic，国内被墙) 和 bootcdn 国外网站现下载，
  gstatic 正是"模型加载很久"的根因。放到 lib 本地同源后，不依赖任何国外网站、
  加载快、内网也能打开。
  注意：这是一次性的基础文件，以后添加新构件不用动它；换电脑/首次上传时
  记得把整个 lib 文件夹一起提交，删了会导致压缩模型打不开。
